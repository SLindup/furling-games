# Fonts

Self-hosted from Google Fonts (latin subset, woff2), so pages make no third-party requests. All are under the SIL Open Font License 1.1.

- Lilita One, Fredoka, Nunito, Caveat: Furling Games pages
- Chakra Petch, IBM Plex Sans, IBM Plex Mono: Sector Defence pages (the same faces the game uses)

`../css/fonts.css` holds the `@font-face` rules.
